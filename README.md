## Which connection count makes sense for a family?

There is no magic number here. Count the screens that are likely to be **playing at the same time**, not every device sitting in a drawer.

A one-connection plan makes sense for a household where only one screen is normally active. Two connections give a couple or small household more breathing room. Three connections start making more sense when parents, children, or different rooms frequently have their own viewing plans.

Four and five connections are aimed at households where simultaneous streaming is a regular thing rather than a once-in-a-while event.

The useful part is that you do not have to buy a completely different content package just to add connections. TiviLive says the full feature set is included across the connection options.
